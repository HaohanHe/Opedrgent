# Opedrgent 使用说明书 / User Manual

**Opedrgent** 是一款开源 Android AI 知识工作站，集多模型对话、语音识别、会议转录、笔记管理、知识发芽、深度研究、日历与健康数据、自动化工作流于一体。

> 本文档面向最终用户，帮助你快速上手并充分利用 Opedrgent 的核心功能。

## 安装与首次启动

### 环境要求

| 项目 | 要求 |
|------|------|
| 系统 | Android 8.0（API 26）及以上 |
| 架构 | arm64-v8a / armeabi-v7a |
| 网络 | 部分功能需要联网（LLM API、搜索、模型下载） |
| 存储 | 建议预留 1GB 以上空间用于模型与录音缓存 |

### 安装方式

1. **下载 APK**：从 Release 页面下载最新 Debug/Release APK。
2. **授予权限**：首次启动时会请求必要的运行时权限，包括：
   - `RECORD_AUDIO`（录音、语音识别）
   - `CAMERA`（录音期间拍照）
   - `CALENDAR`（日历读写）
   - `ACTIVITY_RECOGNITION` + Health Connect（健康数据）
   - `POST_NOTIFICATIONS`（后台任务通知）
   - `FOREGROUND_SERVICE`（保活与下载服务）
3. **配置 API**：进入「设置」->「API 设置」，填写你的 LLM API Key 与 Base URL。

> 提示：本地模型推理需要额外下载 LiteRT-LM 模型并放置到指定目录。

## 主界面与导航

应用采用底部导航栏（手机竖屏）或左侧导航 Rail（横屏/平板）：

| Tab | 名称 | 主要功能 |
|-----|------|----------|
| 🏠 HOME | 首页 | 问候、快捷入口、统计卡片、今日摘要 |
| 📝 NOTES | 笔记 | 笔记列表、文件夹、搜索、新建笔记 |
| 🎙️ RECORDING | 录音 | 录音、实时转写、会议转录、导入音视频 |
| 🤖 AI | 对话 | 多模型聊天、会话管理、流式输出 |
| ⚙️ SETTINGS | 设置 | API、模型、主题、权限、健康、关于 |

### 返回键行为

- **子页面**（如笔记编辑、分享、发芽、图谱）：返回上一级。
- **非首页 Tab**：按返回键回到「首页」。
- **首页**：连续按两次返回键退出应用（第一次提示“再按一次返回键退出”）。
- **录音中**：按返回键会弹出确认对话框，避免误触丢失录音。

## 首页 / Home

首页是应用的入口，提供：

- **问候语**：显示“早上好/下午好/晚上好”以及设备/用户昵称。
- **统计卡片**：今日新增笔记数、知识库文档总数、当前 AI 会话数等真实数据。
- **快捷操作**：新建笔记、开始录音、发起 AI 对话、打开知识库、进入自动化等。
- **最近动态**：最近的笔记、发芽、会话快速预览。

### 顶部对齐说明

首页顶部问候区域与笔记页面顶部保持视觉对齐，避免不同页面出现“忽高忽低”的跳跃感。

## AI 对话 / AI Chat

### 创建会话

1. 切换到 **AI** Tab。
2. 点击右下角「+」或顶部新建按钮。
3. 输入会话标题，开始对话。

### 消息输入方式

- **文本输入**：直接输入问题，支持多行。
- **语音输入**：长按麦克风图标说话，松开后自动发送。
- **附件**：支持导入文件、图片、PDF、DOCX 等作为上下文。

### 模型选择

- 点击输入框上方的模型名称，弹出模型选择器。
- 支持远程 OpenAI 兼容 API 与本地 LiteRT-LM 模型。
- 可切换是否启用 **Thinking Mode**（推理过程展示）。

### 工具调用

Opedrgent 支持 20+ 工具，LLM 会根据你的问题自动判断是否需要调用：

| 工具 | 用途 |
|------|------|
| `web_search` | 联网搜索 |
| `read_url` | 读取网页内容 |
| `deep_research` | 多步深度研究 |
| `run_calendar` | 创建/查询/修改日历事件 |
| `speech_to_text` | 语音转文字 |
| `mimo_tts` | 文字转语音 |
| `run_intent` | 发送邮件/短信/拨号/分享等 |
| `run_js` | 执行 JS Skill |
| `insight_sprout` | 对内容进行知识发芽 |

### 引用与来源

AI 消息中如果使用了网页搜索结果，会显示 **CitationPill** 引用标签，点击可查看来源 URL。

## 录音与会议转录 / Recording

### 录音模式

进入 **RECORDING** Tab，可选择：

- **录音**：使用麦克风录制外部声音。
- **手机内录**：捕获系统内部音频（需要 MediaProjection 授权，Android 10+ 支持）。

### 开始录音

1. 选择录音模式。
2. 点击底部大圆形录音按钮开始。
3. 录音过程中会显示：
   - 实时计时
   - 波形/振幅反馈
   - 实时转写文本（如果启用了 ASR）

### 录音中操作

- **暂停/继续**：点击暂停按钮。
- **标记**：点击标记按钮在关键时刻插入书签。
- **拍照**：点击相机按钮，在录音期间拍摄照片并关联到时间点。
- **完成**：点击停止按钮结束录音。

### 导入音视频转录

1. 点击「导入」按钮。
2. 从文件管理器选择音频或视频文件。
3. 自动进行语音识别并保存为笔记。

### 会议转录

- 录音完成后可选择「会议转录」。
- 支持说话人分离（Speaker Diarization）与多人对话时间轴。
- 转录结果可保存为笔记或生成 AI 摘要。

### 返回确认

录音或暂停状态下按系统返回键，会弹出确认对话框：

> “正在录音：确定要停止录音并返回吗？当前录音将不会保存。”

确认后停止录音并留在录音页；再次按返回键回到首页。

## 笔记系统 / Notes

### 创建笔记

1. 切换到 **NOTES** Tab。
2. 点击右下角「+」或快捷入口的「新建笔记」。
3. 输入标题与正文，选择笔记类型（普通 / 语音转写 / 发芽 / 会议等）。

### 笔记编辑

- 支持富文本编辑器。
- 可插入图片、引用、代码块。
- 支持 Markdown 渲染。

### 文件夹分类

- 长按笔记可移动到文件夹。
- 在笔记列表顶部可切换文件夹视图。

### 知识图谱

- 在笔记详情页点击「图谱」。
- 可视化展示笔记之间的关联、标签、引用关系。

### 分享与导出

- 支持导出为文本、Markdown、DOCX。
- 支持通过 Android 系统分享发送给其他应用。

## 知识库 / Knowledge Base

知识库用于管理长期参考文档，供 AI 在回答时检索引用。

### 添加文档

1. 切换到 **AI** Tab 或从首页进入「知识库」。
2. 点击「导入文档」。
3. 选择 PDF、DOCX、TXT、Markdown 等文件。

### 文档检索

- AI 对话时如果问题涉及知识库内容，会自动调用检索工具。
- 检索结果会作为上下文注入到 system prompt。

### 统计

首页「知识库」统计卡片会显示当前知识库中的文档总数。

## 知识发芽 / Insight Sprout

知识发芽是 Opedrgent 的核心特色功能，通过四阶段 AI 洞察引擎帮助用户从碎片信息中产生洞察。

### 四阶段流程

| 阶段 | 名称 | 说明 |
|------|------|------|
| 1 | 种子提取 Seed | 从输入内容中提取关键概念与问题 |
| 2 | 跨域关联 Connection | 将种子与已有知识进行关联 |
| 3 | AHA 洞察 Insight | 生成新的见解与发现 |
| 4 | 金句回响 Quote | 提炼出可传播的金句 |

### 触发方式

- 在笔记详情页点击「发芽」。
- 在 AI 对话中要求 LLM 对某段内容进行 `insight_sprout`。
- 使用内置 Text Skill `insight-sprout`。

### 上下文注入

发芽过程会按照 **标签 -> 索引 -> 详情** 三层渐进式方式注入上下文，避免一次性塞入过多内容导致 token 浪费。

## 技能系统 / Skills

Opedrgent 支持 V2 标准 SKILL.md 技能，允许用户扩展应用能力。

### 技能类型

- **JS Skill**：在 WebView 沙箱中执行 JavaScript，可通过 `run_js` 工具调用。
- **Text Skill**：纯文本 prompt 模板（V1 遗留，建议迁移到 V2）。

### 导入技能

1. 进入 **设置** -> **技能管理**。
2. 选择：
   - **URL 远程加载**：输入 SKILL.md 或打包的 ZIP 地址。
   - **本地文件导入**：从文件管理器选择技能文件。
   - **手动创建**：直接编辑 SKILL.md 内容。

### 权限控制

每个技能可声明 `require-secret` 级别：

| 级别 | 说明 |
|------|------|
| ALLOW | 直接运行，无需确认 |
| ASK | 每次运行前弹窗确认 |
| DENY | 禁止运行 |

### 内置技能

- `calculate-hash`：哈希计算（SHA-256/SHA-1/MD5）
- `mood-tracker-lite`：心情追踪与趋势仪表盘
- `critical-inquiry`：批判性探究
- `text-refine`：文本精炼
- `mimo-tts`：TTS 语音合成

## 面试模式 / Interview Mode

面试模式提供全双工语音对话体验，适用于模拟面试、口语练习、深度访谈。

### 进入方式

1. 切换到 **AI** Tab。
2. 选择「面试模式」或相关入口。

### 核心能力

- **全双工音频**：同时录音与播放，接近真实对话。
- **硬件 AEC**：回声消除，避免 TTS 声音被麦克风回录。
- **VAD 与打断**：检测到你开始说话时自动暂停 AI 播放（BargeIn）。
- **海马记忆**：维持对话目标，检测话题漂移并自动拉回。

### 使用建议

- 建议在安静环境下使用。
- 使用有线耳机或支持 AEC 的设备可获得最佳体验。

## 自动化 / Automations

自动化工作流允许你配置定时或触发任务。

### 创建自动化

1. 从首页或设置进入「自动化」。
2. 点击「新建自动化」。
3. 配置触发条件（时间、事件、周期性）。
4. 配置执行动作（发送通知、执行 Skill、调用工具等）。

### 后台执行

- 自动化依赖 `AutomationWorker` 与前台服务。
- 请确保授予相关后台运行权限，避免被系统省电策略中断。

## 设置与权限 / Settings

### API 设置

- **Base URL**：LLM API 的基础地址，例如 `https://api.openai.com/v1`。
- **API Key**：你的 API 密钥。
- **Model**：默认使用的模型名称，例如 `gpt-4o`。
- **Temperature / Max Tokens**：可调参数。

### 模型设置

- 远程模型：配置多个 provider preset，快速切换。
- 本地模型：下载 LiteRT-LM 模型后在这里加载。

### 主题

- 支持浅色/深色模式。
- 动态颜色默认关闭，以保留品牌色；可在设置中开启。

### 健康数据

1. 打开「运动健康」开关。
2. 授予 `ACTIVITY_RECOGNITION` 权限。
3. 授权 Health Connect 读取步数、心率、睡眠、卡路里等数据。
4. 授权后，今日健康摘要会自动注入到 AI 对话的 system prompt 中。

### 权限管理

如果某项功能无法使用，请检查：

- Android 系统设置中的权限是否已授予。
- Health Connect 应用中的数据访问权限。
- 是否被电池优化限制后台运行。
