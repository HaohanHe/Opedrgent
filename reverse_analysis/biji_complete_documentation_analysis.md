## 三、四大AI能力体系（"向前一步"）

### 3.1 🌱 发芽——收获意料外的新认知

#### 核心定义
> "AI理解记录内容的'思想内核'，跨越领域找到意想不到的关联"

#### 与搜索的本质区别
| 维度 | 搜索 | 发芽 |
|------|------|------|
| **本质** | 检索和罗列 | 理解和连接 |
| **输入** | 关键词 | 思想内核 |
| **输出** | 相关内容列表 | 跨领域洞察 |
| **AI参与度** | 低（匹配） | 高（理解+生成） |

#### 技术实现（推测）
```
输入：一句话/一段记录
   ↓
思想内核提取
   ↓
跨领域知识图谱检索
   ↓
意想不到的关联发现
   ↓
生成洞察报告
```

#### 产品规则
- **免费用户**：5次/月
- **会员**：无限制
- **前置条件**：每次发芽需先有新录音笔记
- **处理时间**：约3-5分钟（后台处理，异步）

#### 实际案例
> 记录"既往不恋，当下不杂"
> AI关联到：
> - 曾国藩原文
> - 爱因斯坦的类似表达
> - 《功夫熊猫》乌龟大师金句

### 3.2 ✨ 点评——挑出你做得好的地方

#### 核心能力
1. **亮点识别**：主动指出记录中的高光时刻
2. **跨场景关联**：基于记忆库纵向点评
   > "这是你第3次在客户面前先倾听再回应"
3. **正反馈建立**：帮助用户认知自己的成长

#### 与发芽的区别
- **发芽**：向前一步，产生新认知
- **点评**：回顾亮点，强化正向行为

### 3.3 📝 润色——出口就成章

#### 核心能力
- 把凌乱口语变成文从句顺的成品
- 保留"你的声音"，不是AI腔
- 基于得到十年沉淀的"典雅现代汉语"风格

#### 支持场景
- 会议纪要
- 周报
- 公众号文章
- 视频脚本
- 小红书文案
- 朋友圈

#### 技术流程（推测）
```
1. 去口语化
   - 删除口头禅（那个、嗯、就是）
   - 补充省略的主语谓语
   ↓
2. 结构重组
   - 提炼核心论点
   - 重排段落逻辑
   ↓
3. 风格适配
   - 目标平台风格
   - 保留个人特色
   ↓
4. 质量审核
   - 可读性评分
   - 信息密度检查
```

### 3.4 ⚖️ 拷问——诤友随身旁

#### 核心能力
- **批判性思维校验**
- 指出逻辑谬误
- 识别立场风险
- 发现概念偷换
- 苏格拉底式追问

#### 典型问题类型
1. 事实核查："这个数据从哪来？"
2. 假设挑战："如果反过来呢？"
3. 边界探索："适用范围是什么？"
4. 反例寻找："有没有例外情况？"
5. 深度追问："为什么？然后呢？"

#### 与点评的关系
- **点评**：正向强化（做得好的是什么）
- **拷问**：逆向挑战（有什么问题需要想透）

## 九、开放API架构

### 9.1 基础信息
```
Base URL: https://openapi.biji.com
认证: API Key + Client ID
```

### 9.2 核心接口

#### 笔记管理
```http
POST /open/api/v1/resource/note/save    # 保存笔记
GET  /open/api/v1/resource/note/list   # 笔记列表
GET  /open/api/v1/resource/note/detail # 笔记详情
POST /open/api/v1/resource/note/update # 更新
POST /open/api/v1/resource/note/delete # 删除
```

#### 语义搜索
```http
POST /open/api/v1/resource/recall              # 全局语义搜索
POST /open/api/v1/resource/recall/knowledge   # 知识库语义搜索
```

#### 知识库
```http
POST /open/api/v1/resource/knowledge/create           # 创建知识库
POST /open/api/v1/resource/knowledge/note/batch-add   # 批量添加
```

## 十五、关键技术总结

### 15.1 AI能力矩阵

|------|---------|------|------|---------|

## 十八、核心设计模式总结

### 18.1 产品层面
1. **种子→森林**：从一句话长成认知体系
2. **向前一步**：AI主动推动认知进化
3. **四象限AI**：发芽/点评/润色/拷问覆盖认知全周期

1. **异步优先**：耗时操作后台处理
2. **语义优先**：不是关键词，是理解

### 18.3 商业层面
1. **免费→会员→专家**：三层价值阶梯
2. **硬件+软件**：生态闭环
