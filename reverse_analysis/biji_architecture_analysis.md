### 2.2 六大能力详解

#### ① **点评（Evaluation）**
- **触发时机**：用户完成记录后自动触发或手动调用
- **核心价值**：在记录中找到用户的"闪光点"
- **实现逻辑**：
  ```
  输入：用户笔记文本
  ↓
  NLP分析：
    - 提取核心观点
    - 识别创新性表述
    - 评估逻辑完整性
    - 标注精彩语句
  ↓
  输出：结构化点评报告
    - ✅ 亮点清单（3-5个）
    - 💡 改进建议（2-3个）
    - 🎯 下一步方向
  ```

#### ② **拷问（Questioning）**
- **方法论**：苏格拉底式提问法
- **核心价值**：帮用户把想法想透
- **实现逻辑**：
  ```
  输入：用户观点/想法
  ↓
  多角度拷问引擎：
    - 假设检验："如果反过来呢？"
    - 证据质疑："有什么数据支持？"
    - 边界探索："这个的适用范围是什么？"
    - 反例寻找："有没有例外情况？"
    - 深度追问："为什么？然后呢？"
  ↓
  输出：5-8个递进式问题
    - 层次1：事实澄清
    - 层次2：逻辑验证
    - 层次3：假设挑战
    - 层次4：深度拓展
  ```

#### ③ **打磨（Polishing）**
- **目标**：把口语化内容变成可发布的作品
- **支持平台**：小红书/公众号/朋友圈等
- **实现逻辑**：
  ```
  输入：原始记录（口语化）
  ↓
  多轮打磨流水线：
    第1轮：去口语化
      - 删除口头禅（"那个"、"嗯"、"就是"）
      - 补充主语和谓语
      - 修正语法错误

    第2轮：结构优化
      - 提炼核心论点
      - 重新组织段落
      - 添加过渡句

    第3轮：风格适配
      - 小红书风格：emoji + 短句 + 种草语气
      - 公众号风格：长文 + 引用 + 深度分析
      - 朋友圈风格：精简 + 金句 + 个人化

    第4轮：质量检查
      - 可读性评分
      - 信息密度评估
      - 平台规范校验
  ↓
  输出：平台适配的成品内容
  ```

#### ④ **记忆（Memory）**
- **技术基础**：个人知识图谱 + 向量数据库
- **核心能力**：
  - 全域记忆打通（阅读/听课/笔记/摘录）
  - 语义搜索（非关键词匹配）
  - 上下文唤醒（新输入时关联旧记录）
- **实现架构**：
  ```
  记忆系统架构：
  ┌─────────────┐
  │  输入层     │ ← 多模态数据接入
  ├─────────────┤
  │  向量化层   │ ← Embedding模型（可能用DeepSeek）
  ├─────────────┤
  │  存储层     │ ← 向量数据库（如Milvus/Pinecone）
  ├─────────────┤
  │  检索层     │ ← RAG检索 + 重排序
  ├─────────────┤
  │  关联层     │ ← 知识图谱构建
  └─────────────┘
  ```

#### ⑤ **主动（Proactive）**
- **核心理念**："不用你说，主动来帮你"
- **触发机制**：
  ```
  主动推荐引擎：
  ┌──────────────────────────────────────┐
  │ 触发条件检测                         │
  │  - 时间触发：每日/每周复盘提醒       │
  │  - 内容触发：新记录与历史强关联时    │
  │  - 行为触发：用户长时间未使用时      │
  │  - 场景触发：识别到特定使用场景时    │
  ├──────────────────────────────────────┤
  │ 推荐内容生成                         │
  │  - 相关历史记录                      │
  │  - 可能感兴趣的发芽结果              │
  │  - 待完善的笔记列表                  │
  │  - 学习建议                          │
  └──────────────────────────────────────┘
  ```

#### ⑥ **成果（Output）**
- **核心能力**：一个念头→多形态内容
- **支持格式**：
  - 小红书图文
  - 公众号文章
  - 朋友圈文案
  - 会议纪要
  - 学习报告

## 三、"发芽"系统深度剖析

### 3.1 发芽的本质定义
> **从已有记录中，通过AI的多维度分析和关联挖掘，生长出全新的认知和价值**

### 3.2 四大发芽场景（产品层面）

| 场景 | 输入 | 处理逻辑 | 输出 |
|------|------|----------|------|
| **金句收藏** | 单条笔记 | 提取精彩语句 + 情感标注 + 分类归档 | 金句库 |
| **读书听课** | 课程/书籍记录 | 知识点提取 + 思维导图 + 关联扩展 | 学习报告 |
| **灵感发散** | 灵感/想法 | 多角度联想 + 跨领域连接 + 创意扩展 | 洞察集 |
| **会议复盘** | 会议录音纪要 | 要点提炼 + 决策追踪 + 行动项 | 会议报告 |

### 3.3 发芽的技术实现推测（基于公开信息）

```python
class SproutEngine:
    """知识发芽引擎（推测架构）"""

    def __init__(self, llm_client, knowledge_base):
        self.llm = llm_client
        self.kb = knowledge_base  # 个人知识库

    async def sprout(self, input_text, context=None):
        # 阶段1：种子提取
        seeds = await self._extract_seeds(input_text)

        # 阶段2：跨领域关联（使用个人知识库增强）
        associations = await self._associate_domains(
            seeds,
            user_history=self.kb.search(seeds)  # RAG增强
        )

        # 阶段3：洞察生成
        insights = await self._generate_insights(
            seeds,
            associations,
            context=context  # 会话上下文
        )

        # 阶段4：金句回响
        quotes = await self._connect_quotes(insights)

        return SproutReport(seeds, associations, insights, quotes)
```

### 3.4 发芽的价值分层策略

```
免费版（5次/月）：
  └── 基础发芽：种子提取 + 简单关联

会员版（无限次）：
  ├── 完整四阶段流程
  ├── 使用个人知识库增强
  └── 支持自定义领域偏好

专家版（无限次+高级模型）：
  ├── 更强大的LLM（可能是GPT-4级别）
  ├── 更深的关联层次
  ├── 多维度交叉验证
  └── 可导出发芽报告为PDF
```

### 4.1 系统定位
小龙虾 = 得到大脑的**Agent执行框架** + **Skill调度中心**

### 4.2 三大核心能力

#### ① **多形式记录（Multi-modal Input Agent）**
```
输入类型识别器：
┌──────────┬──────────┬──────────┬──────────┐
│  语音     │  图片     │  链接     │  文字     │
│  ↓       │  ↓       │  ↓       │  ↓       │
│ ASR引擎  │ OCR引擎  │ 爬虫引擎  │ NLP引擎  │
│  ↓       │  ↓       │  ↓       │  ↓       │
│ 统一结构化表示                           │
└──────────┴──────────┴──────────┴──────────┘

```

```
    ↓
Vector Search（向量检索）← 用户笔记库
    ↓

    ↓
Context Assembly（上下文组装）
    ↓
Answer Generation（答案生成）
```

#### ③ **自动整理（Auto-organization Agent）**
```
自动整理规则引擎：
┌─────────────────────────────────────┐
│ 时间规则：按创建时间自动分组          │
│ 主题规则：NLP主题聚类                │
│ 情感规则：情感极性分类               │
│ 来源规则：按输入渠道分类             │
│ 关联规则：相似内容自动链接           │
└─────────────────────────────────────┘
```

### 4.4 Skill触发机制（关键！）

```kotlin
// 推测的触发决策引擎
class TriggerDecisionEngine {
    suspend fun shouldTrigger(
        userInput: String,
        context: ConversationContext,
        availableSkills: List<Skill>
    ): Decision {
        // 1. 显式触发：用户明确要求
        if (userInput.containsKeyword(listOf("发芽", "点评", "拷问"))) {
            return Decision.Trigger(matchedSkill)
        }

        // 2. 隐式触发：内容质量判断
        val contentQuality = analyzeContentQuality(userInput)
        if (contentQuality.score > THRESHOLD) {
            return Decision.Suggest(matchedSkill)
        }

        // 3. 上下文触发：对话历史分析
        val conversationPattern = detectPattern(context.history)
        if (conversationPattern == Pattern.DEEP_THINKING) {
            return Decision.AutoTrigger(matchedSkill)
        }

        // 4. 不触发：普通对话
        return Decision.NoAction
    }
}
```

## 五、AI助手"小步"的设计模式

### 5.1 定位
小步 = 得到大脑的**人格化AI助手**（类似ChatGPT的Custom Instructions）

### 5.2 能力矩阵

| 能力域 | 具体功能 | 触发方式 |
|--------|----------|----------|
| **理解** | 语义分析、意图识别 | 自动 |
| **记忆** | 长期记忆、跨会话回忆 | 自动 |
| **评价** | 点评、反馈 | 手动/自动 |
| **引导** | 拷问、追问 | 手动/自动 |
| **创作** | 打磨、生成 | 手动 |
| **推荐** | 主动推送、相关联想 | 自动 |

### 5.3 对话式交互范式

```
传统工具模式：
  用户 → 点击按钮 → 执行功能 → 返回结果

得到大脑的Agent模式：
  用户 → 自然语言表达 → 小步理解意图
       → 自主决策调用哪些Skill
       → 多轮协作完成任务
       → 自然语言返回结果
       → （可选）主动追问或建议
```

## 六、关键技术栈推测

### 6.1 AI模型层
- **ASR**：可能自研或使用科大讯飞/百度语音（支持27种方言+英语）
- **LLM**：DeepSeek-R1（官方已确认用于搜索）、可能还有GPT-4/Claude用于高级功能
- **Embedding**：用于语义搜索和记忆系统
- **多模态**：OCR（图片文字识别）、音频处理

### 6.2 数据层
- **向量数据库**：Milvus/Qdrant/Pinecone（用于RAG）
- **图数据库**：Neo4j（用于知识图谱）
- **对象存储**：文件存储（音频/图片/PDF）

### 6.3 应用层
- **移动端**：Flutter/React Native/Kotlin Multiplatform（跨平台）
- **后端**：微服务架构（Go/Java/Python）
- **实时通信**：WebSocket（同步）
